## 🚀 Портфолио
За час навчання я зрозумів дуже важливу річ: для дата-аналітика замало просто знати інструменти або вміти писати запити. Потрібно вміти правильно презентувати результати своєї роботи так, щоб вони приносили користь бізнесу.

Головним відкриттям для мене став новий погляд на GitHub. Раніше я думав, що це просто складне сховище коду для програмістів. Але тепер я розумію, що це справжня "вітрина" та інтерактивне портфоліо.

Я навчився того, як правильно "упаковувати" свої аналітичні проєкти. Я усвідомив, що голий код або сирі таблиці ніхто детально перевіряти не буде. Тепер я знаю, що будь-який проєкт має супроводжуватися файлом README, де чітко описана бізнес-задача, додані скриншоти візуалізацій (дашбордів) та виділені головні аналітичні висновки (інсайти). Саме розуміння того, як перекладати мову даних на зрозумілу мову бізнесу, я вважаю своїм головним досягненням.
